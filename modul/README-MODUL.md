# Modul Praktikum SIKERJA — Dari Nol Sampai Selesai

Paket ini disusun sebagai tutorial pembuatan website SIKERJA langkah demi langkah, bukan sekadar dokumentasi fitur.

Seseorang yang baru memiliki Laravel 12 kosong dapat mengikuti Modul 00 sampai Modul 22 untuk membangun alur SIKERJA secara bertahap.

## Struktur Setiap Modul

- Tujuan
- Hasil Akhir
- Prasyarat
- Struktur File/Database
- Perintah terminal
- Kode
- Penjelasan
- Pengujian manual
- Kesalahan umum
- Checklist
- Modul berikutnya

## Cara Belajar

1. Mulai dari Modul 00.
2. Kerjakan satu modul sampai berhasil.
3. Jangan lanjut bila masih error.
4. Gunakan Git sebagai checkpoint.
5. Backup database sebelum perubahan besar.

## Target Akhir

SIKERJA dengan role Admin, Pimpinan, Personel; jadwal WFH; presensi foto/GPS; pekerjaan; tugas; laporan; verifikasi; monitoring; evidence privat; PDF; notifikasi; dashboard; UI final; testing; backup; deployment; dan dokumentasi.

## Materi Tambahan untuk Pemula

Selain modul utama, paket ini dilengkapi:

- `KAMUS-ISTILAH-WEB-UNTUK-PEMULA.md`
- `PETA-BELAJAR-PEMULA.md`

Setiap modul juga memiliki bagian **Penjelasan untuk Pemula** yang menjelaskan konsep dengan bahasa sederhana, bukan hanya memberikan kode.

## Versi Penjelasan Gamblang

Versi ini dibuat untuk orang yang benar-benar sedang belajar website.

Pada setiap modul ditambahkan bagian **Penjelasan Gamblang: ... Ini Untuk Apa?**.

Jadi pembaca tidak hanya diberi perintah dan kode, tetapi dijelaskan:

- file ini untuk apa;
- method ini untuk apa;
- perintah terminal ini untuk apa;
- route ini untuk apa;
- controller ini untuk apa;
- model/relasi ini untuk apa;
- kenapa pendekatan tersebut digunakan;
- apa yang terjadi setelah kode dijalankan.

Tambahan penting:

- `KAMUS-ISTILAH-WEB-UNTUK-PEMULA.md`
- `PETA-BELAJAR-PEMULA.md`
- `CARA-MEMBACA-KODE-UNTUK-PEMULA.md`

# Kamus Istilah Website untuk Pemula

Dokumen ini membantu memahami istilah yang sering muncul selama membuat SIKERJA.

## HTML

Bahasa untuk membuat struktur halaman.

Contoh:

```html
<h1>SIKERJA</h1>
```

## CSS

Mengatur tampilan halaman seperti warna, jarak, ukuran, dan layout.

## JavaScript

Membuat halaman dapat berinteraksi dengan pengguna.

Pada SIKERJA digunakan antara lain untuk kamera dan GPS.

## PHP

Bahasa backend yang digunakan Laravel.

## Laravel

Framework PHP yang membantu membuat website dengan struktur yang rapi.

## Route

Menentukan alamat URL dan kode yang harus dijalankan.

## Controller

Tempat logika aplikasi.

## Model

Penghubung antara Laravel dan tabel database.

## Blade

Template HTML milik Laravel.

## Migration

File untuk membuat atau mengubah struktur database.

## Seeder

File untuk memasukkan data awal.

## Middleware

Pemeriksa request sebelum masuk ke controller.

## Session

Menyimpan informasi sementara seperti status login.

## Authentication

Proses memastikan siapa pengguna yang sedang login.

## Authorization

Proses memastikan apa yang boleh dilakukan pengguna tersebut.

## CRUD

```text
Create = Tambah
Read   = Lihat
Update = Ubah
Delete = Hapus
```

## Foreign Key

Kolom yang menghubungkan satu tabel dengan tabel lain.

## Eloquent

ORM Laravel untuk membaca dan menulis database menggunakan model PHP.

## Validation

Pemeriksaan data sebelum disimpan.

## Request

Data yang dikirim browser ke server.

## Response

Data/halaman yang dikirim server kembali ke browser.

## Frontend

Bagian yang dilihat pengguna.

## Backend

Bagian yang memproses data di server.

## Database

Tempat penyimpanan data aplikasi.

## API

Cara dua sistem/perangkat lunak bertukar data.

## HTTP Method

Beberapa method yang sering dipakai:

```text
GET    = mengambil halaman/data
POST   = membuat data
PUT    = memperbarui data
PATCH  = memperbarui sebagian data
DELETE = menghapus data
```

## 403 Forbidden

Pengguna sudah dikenal, tetapi tidak memiliki izin.

## 404 Not Found

Data/halaman/file tidak ditemukan.

## 419 Page Expired

Biasanya terkait session atau CSRF Laravel.

## 500 Server Error

Terjadi error pada backend/server.

## Git

Alat untuk menyimpan riwayat perubahan source code.

## Commit

Checkpoint perubahan pada Git.

## Production

Lingkungan aplikasi yang benar-benar dipakai pengguna.

## Development

Lingkungan saat developer membuat dan menguji aplikasi.

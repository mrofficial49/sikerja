# Panduan Pengguna SIKERJA

## Login

1. Buka aplikasi SIKERJA.
2. Masukkan ID Login.
3. Masukkan password.
4. Tekan tombol **Masuk**.
5. Apabila masih memakai password sementara, sistem akan meminta pengguna mengganti password.

## Panduan Admin

### Mengelola Unit

1. Buka menu **Unit**.
2. Tekan **Tambah Unit**.
3. Isi kode, nama, dan deskripsi.
4. Simpan data.
5. Gunakan tombol status untuk mengaktifkan atau menonaktifkan unit.

### Mengelola Pengguna

1. Buka menu **Pengguna**.
2. Tekan **Tambah Pengguna**.
3. Tentukan role dan unit.
4. Isi identitas pengguna.
5. Simpan akun.
6. Gunakan **Reset Password** apabila pengguna lupa password.
7. Gunakan **Nonaktifkan** untuk menghentikan akses akun.

### Membuat Jadwal WFH

1. Buka menu **Jadwal WFH**.
2. Tekan **Tambah Jadwal**.
3. Tentukan tanggal WFH.
4. Simpan jadwal sebagai draft.
5. Tambahkan Personel.
6. Periksa kembali daftar Personel.
7. Aktifkan jadwal.

### Monitoring

1. Buka **Monitoring & Rekap**.
2. Pilih jadwal.
3. Gunakan filter unit atau pencarian nama.
4. Periksa status check-in, check-out, dan laporan.
5. Tekan **Foto & GPS** untuk melihat bukti presensi.
6. Tekan **Lihat Laporan** untuk membuka laporan Personel.

### Verifikasi Laporan

1. Buka **Verifikasi Laporan**.
2. Pilih laporan berstatus menunggu verifikasi.
3. Periksa pekerjaan dan bukti PDF.
4. Pilih:
   - **Setujui**, apabila laporan benar.
   - **Minta Revisi**, apabila perlu diperbaiki.
5. Tuliskan catatan yang jelas saat meminta revisi.

## Panduan Pimpinan

### Memberikan Tugas

1. Buka menu **Tugas Personel**.
2. Tekan **Berikan Tugas**.
3. Pilih jadwal dan Personel.
4. Isi judul tugas.
5. Isi uraian dan hasil yang diharapkan.
6. Simpan tugas.
7. Personel akan menerima notifikasi.

### Memantau Personel

1. Buka **Monitoring & Rekap**.
2. Pilih jadwal WFH.
3. Periksa status kehadiran dan pekerjaan.
4. Buka bukti foto serta GPS bila diperlukan.

### Memverifikasi Laporan

1. Buka **Verifikasi Laporan**.
2. Pilih laporan.
3. Periksa hasil pekerjaan.
4. Setujui laporan atau minta revisi.
5. Personel akan menerima notifikasi hasil pemeriksaan.

## Panduan Personel

### Check-in

1. Login pada tanggal WFH.
2. Buka menu **Presensi**.
3. Izinkan browser menggunakan kamera.
4. Izinkan browser menggunakan lokasi.
5. Ambil foto.
6. Pastikan GPS berhasil diperoleh.
7. Isi alasan apabila terlambat.
8. Tekan tombol check-in.

### Membuat Rencana Kerja

1. Setelah check-in, buka **Pekerjaan**.
2. Tekan **Tambah Rencana Kerja**.
3. Isi judul pekerjaan.
4. Isi uraian pekerjaan.
5. Isi target hasil.
6. Simpan.

Rencana pribadi tidak wajib apabila Personel sudah menerima tugas dari Pimpinan.

### Memperbarui Pelaksanaan

1. Buka pekerjaan.
2. Tekan **Perbarui Pelaksanaan**.
3. Pilih status pekerjaan.
4. Isi progres.
5. Isi kendala apabila ada.
6. Isi rencana tindak lanjut.
7. Upload bukti PDF bila diperlukan.
8. Simpan perubahan.

### Mengirim Laporan

1. Pastikan semua pekerjaan aktif sudah diperbarui.
2. Buka **Laporan & Check-out**.
3. Periksa ringkasan pekerjaan.
4. Tekan **Kirim Laporan**.
5. Status berubah menjadi **Menunggu Verifikasi**.

### Check-out

1. Laporan harus sudah dikirim.
2. Buka halaman check-out.
3. Izinkan kamera dan GPS.
4. Ambil foto check-out.
5. Pastikan lokasi diperoleh.
6. Tekan tombol check-out.

### Revisi Laporan

1. Buka notifikasi revisi.
2. Baca catatan Pimpinan atau Admin.
3. Perbaiki pekerjaan.
4. Kirim ulang laporan.
5. Check-out tidak perlu dilakukan kembali apabila sebelumnya sudah selesai.

## Notifikasi

Pusat notifikasi menampilkan:

- Jadwal WFH.
- Perubahan jadwal.
- Tugas baru.
- Laporan menunggu verifikasi.
- Permintaan revisi.
- Persetujuan laporan.

Tekan notifikasi untuk membuka halaman terkait.
